Sources and privacy

Each code records the sites listing it and the date we last saw it there. The browser extension tries a store's codes at checkout and keeps the one giving the lowest total. The extension sends nothing on its own; when a code you typed works and is missing here, it asks whether to share that code, and sharing sends the store and the code alone.
